# Архив документации

Эти материалы сохранены для истории проекта. Упоминания незавершённой
реализации, JSON v1, прежних фильтров и старых результатов проверок относятся
к моменту создания соответствующего документа.

Актуальные сведения: [README проекта](../../README.md),
[аналитика](../ANALYTICS.md), [последние проверки](../VERIFICATION.md).

| Документ | Происхождение |
|---|---|
| [PLAN.md](PLAN.md) | Первоначальный план реализации, ранее в корне проекта |
| [TECH_HANDOFF.md](TECH_HANDOFF.md) | Предварительный технический план и предполагаемый контракт, ранее в корне |
| [CODER_PROMPT.md](CODER_PROMPT.md) | Задание агенту для первоначальной реализации; не текущие инструкции |
| [STARTER_README.md](STARTER_README.md) | Исходное описание незаполненной заготовки из `case/starter/README.md` |
| [VERIFICATION_HISTORY.md](VERIFICATION_HISTORY.md) | Предыдущие проверки до обновления рабочего интерфейса |

Содержимое первоначальных планов сохранено. Указанные в них пути следует
читать относительно прежнего расположения файлов, как отмечено в начале
каждого документа.
