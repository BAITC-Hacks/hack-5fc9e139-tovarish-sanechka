# Первичный профиль данных

Получен из исходных Parquet после проверки сумм и количества операций по каждой паре.
Python 3.12.13; версии библиотек зафиксированы в uv.lock.

- 2 248 узлов, 3 119 направленных рёбер, 4 840 операций, 81 seed.
- Период: 1–31 июля 2026; оборот рёбер 365 890 012 KZT.
- 19 изолятов (все seed): полный граф содержит 35 слабосвязных компонент,
  граф участников рёбер — 16. Изоляты включены в PageRank.
- 444 узла depth=4 без исходящих: нельзя считать конечными получателями
  лишь по отсутствию наблюдаемого выхода.
- 97 повторяющихся строк операций сохранены: их идентичность не доказывает
  ошибку выгрузки. Пропусков, повторных gid и повторных пар рёбер нет.
- Сумма оборотов не равна уникальной денежной массе.
