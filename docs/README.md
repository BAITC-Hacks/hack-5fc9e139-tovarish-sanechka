# Документация проекта

Текущее устройство системы, стек, архитектурные решения и команды запуска
описаны в [корневом README](../README.md). Ниже — подробности по отдельным темам.

Перед сдачей: [запуск](../README.md#4-установка-запуск-и-проверка) →
[проверки](VERIFICATION.md) → [репетиция и комплект сдачи](DEMO.md).
Для работы без API-ключа достаточно обычного запуска: выключается только
ассистент. Подробности — в [ASSISTANT.md](ASSISTANT.md).
