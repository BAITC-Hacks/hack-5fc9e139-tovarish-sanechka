# Интерфейс «Граф денег»

Рабочий экран AML-аналитика. Сценарий: выбрать узел по приоритету или
найти gid → прочитать гипотезу и оговорки → проверить направленные связи.
Объекты: узел, перевод, кластер, приоритет. Успех — найти любой исходный
узел и объяснить его роль без обязательного взаимодействия с canvas.

Основа — React/Vite, native controls, обычная таблица, Cytoscape напрямую.
Ориентиры — плотность Carbon и организация рабочего экрана PatternFly.
Большая компонентная библиотека пока не нужна: редактирования и сложных форм нет.

Направление: холодный спокойный рабочий стол, три соседние области
«приоритеты | карточка | связи». Без рекламного hero и декоративных KPI.
Подпись проекта — наблюдаемые входящий и исходящий потоки со стрелкой
в карточке, повторяющей направление рёбер. Преимущество перед единым большим
canvas — основания роли читаются рядом с графом.

Палитра: фон #edf2f6, поверхность #ffffff, текст #20394c,
вторичный текст #526b7c, действие #2165ac, границы #d4dfe7.
Тёплая оговорка #fbf5e9 отделяет ограничения данных от ошибки приложения.
Georgia только в заголовке проекта, Arial/Helvetica для управления,
monospace для gid. Шрифты системные, внешних запросов нет.

Роль кодируется цветом и текстом; приоритет отображается числом.
Объяснение выше дополнительных метрик. Альтернативные роли, кластер и
слагаемые приоритета раскрываются по запросу. Полные gid никогда не
преобразуются в JavaScript number. На графе только суффикс, полный gid в карточке
и таблице связей. Поиск всегда по всем узлам независимо от фильтров.

На ширине ≤760 px порядок: поиск → карточка → связи → приоритеты.
Граф ограничен 80 узлами с явным счётчиком и кнопкой расширения.
Координаты сохраняются при смене выбора; автоматической силовой раскладки нет.
Таблица всех связей доступна с клавиатуры, длинный список прокручивается.

Состояния: загрузка, ошибка с повтором, повреждённый файл, пустой фильтр,
неизвестный gid, изолят. Фокус видимый, нативные labels и кнопки обязательны.
Не показывать внутренние термины pipeline, schema_version или названия библиотек
в основном пользовательском сценарии.

Проверено локально Playwright: три сценария, реальные результаты, поиск,
фильтры, изолят, неизвестный gid, карточка, связи, CSV, отсутствие внешних
запросов, загрузка/ошибка/повтор. Скриншоты 1280×720 и 390×844 просмотрены.
Контейнерная проверка должна быть выполнена отдельно после Docker-поставки.
