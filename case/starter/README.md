# Расчётное ядро «Граф денег»

Каталог содержит реализованный пайплайн на основе стартового кода кейса.
`starter.py` проверяет три Parquet-файла, строит полный направленный граф,
рассчитывает признаки, кластеры, пути и устойчивость сети. `scoring.py`
назначает объяснимые роли и приоритеты по конфигурации.

## Запуск расчёта

Из корня репозитория, в окружении Python 3.12:

```sh
uv sync --locked
uv run python case/starter/starter.py --data case/data --out out --config config.toml
```

На выходе — заполненные `nodes_roles.csv`, `clusters.csv`, `top_nodes.csv`
и `analysis.json` с `schema_version=2`. На исходном датасете роли присваиваются
всем 2 248 узлам, включая 19 изолятов. HTTP-сервер эта команда не запускает.

Для приложения целиком используйте Docker Compose или `run.py` по
[корневому README](../../README.md#4-установка-запуск-и-проверка).
`uv.lock` задаёт воспроизводимое окружение; `requirements.txt` содержит
согласованные прямые зависимости для установки через pip.

## Контракт и ограничения

- Суммы и количество операций из `transactions.parquet` сверяются с агрегированными рёбрами.
- Направления и веса переводов сохраняются; ненаправленная проекция используется для Louvain.
- Обрыв четвёртого шага и неполные входящие исходных клиентов учитываются при назначении ролей.
- Дневная близость переводов — признак, а не доказательство движения одной суммы.
- Выходные схемы, диапазоны скоров, объяснения и даты проверяются перед записью файлов.
- Эксклюзивная POSIX-блокировка запрещает параллельную запись в один каталог результата.
